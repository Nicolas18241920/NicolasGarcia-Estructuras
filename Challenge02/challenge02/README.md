# Angular Data Structures: Linked Lists Assignment

This Angular application demonstrates two custom linked list data structures implemented in TypeScript:
1. **Singly Linked List**: Music playlist navigation (play next song).
2. **Doubly Linked List**: Browser history navigation (go back and forward).

## Setup & Running
1. Clone repository: `git clone <your-repo-url>`
2. Install dependencies: `npm install`
3. Run local server: `ng serve`
4. Open browser at `http://localhost:4200`
